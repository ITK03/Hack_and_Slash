# Descent — 検証用プロトタイプ

スマホ縦画面向けハクスラの **仕様確定用プロトタイプ**。
製品コードではない。仮説に答えを出したら捨てて作り直す前提。

**`index.html` 1枚で完結**（ビルド不要・依存なし・サーバー不要）。
ブラウザで開くだけで動く。セーブは端末の localStorage。

## 遊び方

拠点 →「潜る」→ ダンジョン。

| 操作 | 内容 |
|---|---|
| 画面左半分をドラッグ | 移動（どこを触ってもそこが原点になる） |
| 通常攻撃 | **自動**。射程に入ると勝手に出る |
| 右下ボタン | 突進斬り / 衝撃波 |
| オレンジの輪 ▼ | 下の階への階段 |
| 青い輪 | 帰還ポータル（開始地点） |
| 画面端のオレンジ矢印 | 階段の方向 |

**拾ったアイテムは未鑑定のまま。帰還して初めて中身が分かる。**
**死ぬとその潜行で拾ったものは全部失う。**

---

## 検証したい6つの仮説

遊んだ後、これに答えてほしい。

| # | 仮説 | 見るところ |
|---|---|---|
| 1 | 殴った時に気持ちいい | ヒットストップ・画面揺れ・数字・音。**手応えが無ければ他は全部無意味** |
| 2 | 縦画面のアイソメで視界が足りる | 敵の接近に気づけるか。狭すぎないか |
| 3 | **「潜るか帰るか」が本物のジレンマになる** | 毎回迷うか。それとも「すぐ帰る」か「無視して潜る」の一択か |
| 4 | 未鑑定 → 帰還後の鑑定が楽しみになる | 帰る途中「何だろう」と思うか。鑑定の瞬間が山場になるか |
| 5 | ラン内3択が多様性を生む | 毎回違う戦い方になるか。ただのノイズか |
| 6 | 光の柱が刺さる | オレンジの柱が立った時に反応するか |

### 聞き方（重要）

友人には **「面白かった？」と聞かない**。必ず「面白かったよ」が返ってくる。

代わりにこれを聞く:

- **どこで止めたくなった？**
- 一番気持ちよかった瞬間は？
- 何回目で飽きた？
- **翌日、自分から開いた？** ← これが唯一信用できる指標

拠点の「プレイログを表示」→「コピー」で JSON が取れる。

## 調整

`index.html` 冒頭の `CFG` にすべての数値が集約されている。
ここだけ触れば大抵の調整はできる。

| 特に効くもの | 説明 |
|---|---|
| `TILE_W` / `TILE_H` | 視界の広さ ← 仮説2 |
| `LIGHT_R` / `DARKNESS` | 暗さと可視範囲 |
| `HITSTOP` / `SHAKE_*` / `KNOCKBACK` | **手応えの本体** ← 仮説1 |
| `ATK_CD` / `ATK_DMG` | 戦闘テンポ |
| `RARITY` | ドロップ品質 ← 仮説6 |
| `HP_SCALE` / `DMG_SCALE` | 深度ごとの難易度上昇 ← 仮説3 |

### 現状の難易度曲線（装備なしで自動計測）

| 深度 | 死亡率 |
|---|---|
| 1〜3 | 0% |
| 5 | 13% |
| 8 | 38% |
| 12 | 75% |
| 16+ | 100% |

素の状態だと深度8〜12が壁。装備を持ち帰って強くなると先へ進める、という設計。

## 公開方法（Cloudflare Workers）

GitHub Pages は無料プランの private リポジトリでは使えないため Cloudflare を使う。
本実装で使う D1 と同じアカウントに収まる。

`wrangler.jsonc` が静的アセット配信の設定。**`./public` だけを配信する**ので、
`docs/`（マネタイズ戦略を含む）は公開されない。ここは変えないこと。

Cloudflare 側の設定:

| 項目 | 値 |
|---|---|
| Build command | 空欄 |
| Deploy command | `npx wrangler deploy` |
| Root directory | `/` |
| **Branch** | **現在の作業ブランチ（Codex では通常 `work`）** |

`main` や存在しない `claude/...` ブランチを指したままだと、Codex 側で読めない／配信対象が見つからないことがある。

現在の実プレイURLは `https://hack-and-slash.luyinshele.workers.dev`。
デプロイ後は `https://hack-and-slash.<サブドメイン>.workers.dev` 形式で開ける。
以降は push するたびに自動更新される。

URL を送るだけで友人が遊べる。インストールも登録も不要。
