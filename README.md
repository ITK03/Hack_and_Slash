# Descent — モバイル向けハックアンドスラッシュ

縦持ちのブラウザゲーム。**`public/index.html` の1ファイルで完結**する（ビルド工程なし・外部ライブラリなし）。
Cloudflare Workers の静的配信で動く。

---

## ファイル構成

```
public/index.html     ゲーム本体。これがすべて（約5,500行）
scripts/              検査スクリプト（Node）
  game-env.mjs        index.html を Node の vm + DOM スタブで動かす土台
  check-*.mjs         各種の検査
```

## 守ること

1. **外部ライブラリを足さない。ビルド工程も増やさない。** `public/index.html` 単体で動くこと。
2. **検査スクリプトにゲーム本体の式・定数・確率を書き写さない。**
   必ず `public/index.html` を読み込んで、その中の関数と状態を呼んで計測する。
   写した数字を検査すると、本体を変えても検査が通ってしまう。
3. **`npm run check` が通らない状態で完了報告しない。**
4. **目標値・検査内容を緩めて通さない。** 通らないなら、通らなかった事実と実測値を出す。
   *設計そのものを変える指示*を受けた場合だけ目標を動かしてよく、その時は
   旧値・新値・理由を併記する。
5. **計測が目標を外れたら、まず「ゲームが壊れている」のか
   「計測方法が実態と合っていない」のかを切り分ける。**
   基準を動かしてよいのは後者と確認できた場合だけ。
6. `docs/SPEC.md` を、変更内容と**理由**で更新する。
7. **作業の区切りごとに push する。溜めない。**

### 触ってはいけないもの

- **管理者モード**（設定のコード入力欄）は検証用。**リリース時に機能ごと削除する**前提。
- **プレイヤー間のアイテム交換は実装しない。** 複数アカウントで壊れるため。
- **課金アイテムが増殖しうる仕組みを作らない。**
- 共有時に個人のアカウントが見えないよう、表示名は端末内の自由入力にとどめる。

## 検査

```bash
npm run check          # 8種。うち check-balance と check-bundle-b は各15〜20分かかる
npm run check:layout   # 枠の重なり・切れ・画面外（要 Playwright）
npm run check:ui       # 枠の不揃い・はみ出し・44px・コントラスト（要 Playwright）
npm run check:playable # 初回起動からボスまで実際に遊んで通す（要 Playwright）
```

**`check-balance` が15分返らないのは正常。** ボス床の死亡率を別枠で測るため。
**時間で打ち切らないこと。打ち切ったものは「未確認」であって「成功」ではない。**

Playwright が無い環境では後半3つは自動でスキップされる。
**スキップは「通った」ではない。** 入るなら `npx playwright install chromium`。
入らないなら、**その旨を申告すること。**
過去に、この3つを飛ばしたせいで画面の枠が重なったまま出荷された事故がある。

## 計測でつまずいた記録（同じ罠を踏まないために）

`docs/SPEC.md` に詳しいが、要点だけ:

- **50%死亡深度の二分探索は、5層ごとのボス床に振り回されて階段状に飛ぶ。**
  手ごたえの上下を見るなら、ボス床を外した**通常床の死亡率**を使う。
  同じ罠を3回踏んでいる。
- **試行64回では死亡率の揺れが±6pt**あり、判定の閾値と同じ大きさのノイズが乗る。192回にする。
- **装備の深度は、戦うフロアの深度に合わせて測る。** 深度50の装備で深度30を殴ると
  全部一撃で倒せてしまい、属性倍率も消耗品の差も見えなくなる。
- **敵HPを上げると、属性を合わせる価値が下がる。** 一撃で倒せていた相手が倒せなくなり、
  共鳴の倍率が余分な一振りに吸われるため。難易度は**攻撃力側**で上げる。

## 配信

```bash
npm run serve     # ローカル確認（http://localhost:8000）
npm run deploy    # Cloudflare Workers へ
```

`wrangler.jsonc` の `directory` は必ず `./public`。
`./` にすると `docs/`（収益計画を含む）まで公開されてしまう。
