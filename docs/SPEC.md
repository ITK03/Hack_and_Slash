# Descent 仕様書

> 対象: `public/index.html`。本書は実装変更のたびに更新する。

## 検証の原則
- 検証スクリプトにゲーム本体の式・定数・確率を書き写してはならない。
- 必ずヘッドレスブラウザで `public/index.html` を実行し、その中の関数と状態を呼び出して計測する。ブラウザ実行には devDependency の Playwright を使う。
- 「特定の文字列がファイルに存在するか」だけの確認は検証とみなさない。

## 画面構成（拠点タブ、ダンジョン HUD、ポップアップ）
- 初回は戦士/魔術師のクラス選択と操作訓練を行い、以後は拠点から潜行する。
- 拠点下部は「拠点」「装備」「倉庫」「商店」「設定」の5タブ。
- 拠点タブはプロフィール、最大深度、編成、開始深度選択、潜行ボタンを表示する。
- 装備タブは7スロットと能力値/ポイント割り振り、倉庫は絞込・整列・売却を扱う。
- 商店はガチャ、ジェム購入、ゴールド商品のサブ画面、設定は表示項目と管理機能を持つ。
- ダンジョンHUDはHP/MP/XP、深度、所持金、DPS、時間、戦利品、ミニマップを表示する。
- 画面下に移動スティック、通常攻撃、3スキル、ポーション、状況依存アクションを置く。
- ボス戦では画面上部にボス名とHPバー、状態異常/バフとコンボもHUDに重なる。
- 一時停止画面は「戦利品」「装備・能力」「設定」の3タブと再開/断念操作を持つ。
- ポップアップはレベルアップ選択、装備詳細/強化/編成、確認、宝箱解錠、通知を扱う。

## 状態（S）の主要フィールドとセーブ形式
- `S` は画面/職業/プレイヤー、現在深度と最深度、敵・弾・描画物、階段/門/ボスを保持する。
- `bag` は未帰還品、`stash` は倉庫、`gear` は現キャラ装備、`mats` は素材の種類/階梯別カウンタ。
- `base` はレベル、XP、未使用能力点、6基本能力、`p` はそこから導出した戦闘中能力とHP/MP。
- `characterStates` はキャラクター別の `base`/`gear`、`formation` は出撃順を保存する。
- ラン時間/獲得金/開始階/戦闘ログ、タブ、設定、チュートリアル、管理者状態も `S` にある。
- 保存先は localStorage の `descent_v5`、JSONオブジェクトとして永続フィールドだけを書き出す。
- 敵、弾、マップ、現在ランの一時描画物などは保存せず、潜行開始時に再生成する。
- ロード時は旧リング名、廃止ベルト、旧主能力、旧装備名、旧能力スキーマを移行する。
- 欠けたフィールドには既定値を補い、職業/キャラクター別状態と現装備を再接続する。

## 戦闘（通常攻撃・スキル・状態異常・敵AI・ボス）
- 通常攻撃は職業の物理/特殊攻撃、射程、攻撃速度を使い、基礎倍率は0.34。
- 戦士は薙ぎ払い/突進斬り/大地砕き、魔術師は火球/氷結新星/連鎖雷撃をMPで使う。
- クリティカル、回避、防御/軽減、吸収、ノックバック、クールダウンとMP回復がある。
- 燃焼/毒は最大HP割合の継続ダメージ、凍結/麻痺は行動阻害として敵味方に付く。
- 通常敵は追跡、跳躍、突進、距離維持射撃、自爆など種類固有AIを持つ。
- エリートは氷結、業火、守護、分裂、迅雷、再生、爆散の特性を一つ得る。
- 5深度ごとに3種から巡回するボスが出現し、専用HP/攻撃曲線と予兆攻撃を使う。
- ボスはHP半分で激昂し、速度と攻撃間隔が強化され、撃破で次深度を解放する。
- 伝説固有効果やラン中レベルアップ選択は攻撃、範囲、回復、軽減、ドロップを修飾する。

## 装備（スロット、レア度、オプション、合成）
- スロットは武器、兜、鎧、手袋、靴、指輪、首飾りの7枠（武器/防具には職業適性あり）。
- レア度は並、上質、希少、秀逸、伝説の5段階で、付与オプション数は0〜6。
- 主能力は部位基礎範囲×`ilvl^0.62`、不適性防具の主能力は60%になる。
- オプションは攻撃、HP、防御、会心、速度、吸収、短縮、運などから重複なしで抽選する。
- 品質係数は0.5〜1.55で、表示上は高品質/低品質の印を付ける。
- 伝説には装備中だけ働く固有効果を一つ付け、名称とアイコンは部位/職業から生成する。
- 合成は素材装備をXPとして消費する既存経路と、結晶で1段階上げる経路を併設する。
- 素材装備からXPを入れる場合も、実際に段階が上がるごとに対象階梯以上の結晶を消費する。
- 強化上限は `10 + floor(sqrt(ilvl))`（深度100で20、1000で41）で装備ごとに決まる。
- 主能力は強化1段階ごとに基礎値の14%を加算し、強化済み値への乗算（複利）はしない。
- 合成XPの次レベル必要量は装備深度の平方根で緩やかに増え、強化レベル自体による指数増加は行わない。
- 強化素材は結晶と核のみで、階梯は `max(1, ceil(log2(ilvl/10+1)))` とする（深度1〜10は階梯1）。
- 上位階梯は1個を下位4個相当として代用できるが、下位から上位への変換はできない。
- 分解結晶は並1/上質2/希少5/秀逸12/伝説30個を基準に、生成深度の平方根スケールを掛ける。周回で得る結晶も同率で増やし、上限レベルが深度とともに増えても必要潜行数が発散しない設計とする。
- 強化上限の後半1/3では結晶に加えて同階梯以上の核1個を段階ごとに消費する。
- 売却価格、合成費、素材XPは装備深度、レア度、強化段階から計算する。

## 進行（XP曲線、階層スケーリング関数、ドロップ率）
- レベル上限は100、レベルごとに能力点5を得て6基本能力へ任意配分する。
- 累積XPはLv1/10/20/30/40のアンカーを1.7乗補間し、Lv40以降は1.1128倍で外挿する。
- Lv100後はLv99→100必要XPを固定周期としてXPを蓄積し、パラゴンごとに能力点1を得る。
- パラゴン能力点は通常と同じ6基本能力UIで無制限に配分でき、旧 `para` も初回移行時に返還する。
- 通常敵HP/攻撃とボスHP/攻撃は深度45まで区分線形、以後は末尾傾きで線形外挿する。
- 敵数は深度に比例して増えるが46体で頭打ち、速度も上限1.0の関数で決まる。
- 装備深度は生成深度の整数値、主能力はその0.62乗、オプションも深度依存式で伸びる。
- 通常敵の装備ドロップ率4.8%、金42%、ポーション7%、欠片13%、宝箱生成3.5%。
- レア度重みは深度では変わらず、アイテム発見率と運が希少以上の重みだけを増やす。
- ボス/エリート/宝箱/壺は個別の確定または補正付き報酬処理を持つ。
- 雑魚と樽は低確率で結晶、ボスは撃破ごとに核を1個落とし、いずれも現在深度の階梯になる。
- 帰還またはボス撃破で進行を保存し、解放済み深度は5刻みの開始地点から選べる。

## 経済（ゴールド、課金通貨、ガチャ）
- ゴールドは敵/宝箱/壺、装備売却で得て、合成、能力振り直し、商店購入に使う。
- 潜行中の取得ゴールドと装備は帰還時に確定し、全滅/断念では未帰還分を失う。
- 課金通貨は `premium`（◆）としてゴールドと別管理し、商店の購入操作で補充できる。
- キャラクターガチャは300◆、未解放キャラを優先して解放しプロフィール候補にも加える。
- 装備ガチャは200◆、最大到達深度相当の装備を生成し、最低でも上質を保証する。
- チュートリアルでは装備ガチャとキャラクターガチャを各1回無料で固定報酬にする。
- レア抽選、通常ドロップ率、ガチャ機能そのものは進行バランス変更の対象外とする。
- 倉庫の売却選択UIを分解にも流用し、装備中を除外した複数装備を確認後に結晶化する。

## 実装後の検証基準
- ヘッドレス戦闘botはゲーム本体のフロア生成、装備生成、戦闘 `update()` を実行し、各深度の複数試行から死亡率50%の境界を計測する。
- 到達時レベルは既存XP目安から、素手Lv10、標準Lv60、厳選Lv90とする（Lv100未満）。
- 死亡率50%の実測値は素手10、希少7枠/品質1.0/半強化67、伝説7枠/品質1.4/最大強化112。
- 深度100で標準プロファイルの死亡率は99%超となり、標準装備だけではクリアラインに届かない。
- `npm run check` は構造回帰、上記botの目標範囲、強化経済の実測、深度1000への実際の潜行をまとめて検査する。
- 既存セーブはロード移行を維持し、旧パラゴン値のみ一度だけ能力点として返還する。
- 素材未保存の旧セーブは結晶/核とも0で開始し、深度3装備は何個分解しても階梯3以上を生まない。
- 階梯の旧定義で保存された結晶・核は、初回ロードで階梯キーを1つ下へ移す（階梯1は1に留めて合算）。
