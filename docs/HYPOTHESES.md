## 1. 何を作るか

**シナリオ無し・無限降下型ハクスラ。**
Diablo 1 の階層降下 + Diablo 2 のアイテム + Diablo 3/4 の戦闘テンポとメタ進行。

核となる構造は3層の合成。**既存のどのゲームにもない組み合わせで、各層は個別に実証済み。**

| 層 | 出典 | 内容 |
|---|---|---|
| 永続ビルド | Diablo | 装備を集めて強くなる |
| ラン内ビルド | Survivor.io | 潜行中のレベルアップ3択。**レベル1でもビルドが発生し、time-to-fun が60秒に落ちる** |
| 持ち帰りリスク | Wizardry / Tarkov | 拾ったものは帰るまで自分のものではない |

1潜行: 装備を整える → 潜る → 3択で今回のビルドを作る → 深いほど良い未鑑定品 →
**潜るか帰るか** → 帰還して鑑定（山場）→ 装備更新 → もっと深く

### 未鑑定システムが中核

Diablo の光の柱は「予期」で脳汁を出す。予期の窓は約3秒。
**未鑑定にすると窓が潜行1回分に伸びる。Diablo より強い。**
しかも**ガチャの快感を、ガチャの課金構造と評判コストなしで**内蔵できる。

## 2. ターゲットと雰囲気

**ディアブロ層。** ハイブリッドカジュアル寄りの明るい絵は Archero / きのこ伝説と
同じ棚に並ぶが、あそこは広告費の殴り合いで、宣伝予算ゼロでは勝てない。

| 理由 | |
|---|---|
| 能動的に探す層 | 宣伝ゼロなら「探しに来る人」を狙うしかない |
| モバイルで供給が枯れている | モバイルARPGはガチャばかり |
| 彼らは喋る | Wiki・ビルドガイド・動画 = 無料の宣伝 |
| 金を使う | ミッドコアは90%がIAP中心 |
| **見た目より仕組みで評価する** | **絵が弱く systems が強い開発者に最適** |

差別化メッセージ: **「P2Wじゃない、スマホのDiablo」**
Diablo Immortal は2週間で500万DL / $24M（需要は証明済み）、炎上の原因は100% P2W。

### アートは「シルエット + 発光」

**逆光のシルエットにすると、元絵が粗いか精緻かを原理的に判別できない。**
AI が絵を苦手とする弱点が消える。CC0素材（Kenney等）は形の供給源として使い、
個性はライティングとエフェクトで作る。

副次効果: 暗背景ではエフェクトが少量で映える（制作コストが下がる）、
小画面で最も読みやすい、一目で客層に正しい信号が出る。

### アクセシビリティ = カジュアル化ではなく「摩擦の除去」

オート攻撃、段階的開示、無料リスペック、ラン内強化。
**層は変えず、同じ層の中で脱落する人を減らす。**
狙うのは「Diabloをやりたいが時間がない/PCがない/挫折した」層。

## 3. マネタイズ

**課金メイン + リワード広告。広告メインは選ばない。**
非課金者の広告 ARPDAU $0.08〜0.15 に対し、課金を乗せた混合は $0.15〜0.50。
ミッドコアは業界全体で90%が IAP 中心。

### 売るもの

| 層 | 商品 |
|---|---|
| A. 時短 | XP/ドロップブースト、コンディション即時回復、鑑定の即時化 ← **ARPPUの本体** |
| B. 幅 | キャラスロット、スタッシュ拡張 |
| C. コスメ | スキルエフェクト、武器トレイル、**光の柱の色**、称号 ← コード実装＝強み |
| D. プレステージ | サポーターパック $30〜$500、累計支援バッジ |

**ハード通貨（ジェム）あり。** 権利フラグだけだと生涯課金額が $100〜200 で頭打ちになり、
whale が構造的に存在できなくなる。PoE が「課金通貨 + P2Wなし + ガチャなし」で
最高水準の評判と巨額収益を両立している。

### 越えてはいけない一線

> **時間で払うか、金で払うか。到達点は同じ。**

- ❌ 課金しないと届かない上限 / ガチャ / 装備・戦闘力の直接販売
- ❌ **買ったものの後からの弱体化・無料配布**（whaleの士気を殺す最大要因）
- ✅ PvPも交換も無いので、課金者が速く進んでも他人の体験は劣化しない

### 難易度は固定

深度がそのまま難易度。**無料で難易度を下げられるなら「楽さ」に値段がつかない。**
ただし無限降下なので壁ではなく到達深度の問題で、誰も締め出されない。

## 4. 不正対策

**論点は「接続の有無」ではなく「誰がそのデータを持っているか」。**
オンライン必須 ≠ サーバー権威。常時接続でも、サーバーが持たないデータは守れない。

### 構造で被害を消す

| 判断 | 効果 |
|---|---|
| **アイテム交換なし** | 増殖しても他人に影響しない。**これで対策費用が100倍変わる** |
| ソフト通貨とハード通貨を分離、両替所なし | ソフトの増殖がハードの価値を毀損しない |
| 力を売らない | 増殖されても課金者が損しない |

### 権威の配置

時短を売る以上、**進行に繋がる全データがサーバー権威**（レベル・装備・ゴールド・
ジェム・深度記録・課金の権利）。クライアントは表示用キャッシュのみ。

- 課金の検証: 端末は transactionId を送るだけ → サーバーが Apple/Google に直接照会
- 主防御: **シード整合性検査**（再シミュレートせず、シードから生成される正解と照合）
- 副: リプレイ検証（上位・フラグ付きのみ。全件は CPU 的に不可能）
- 異常検知（進行速度・ドロップ率・DPS）
- 検知しても即BANせず**シャドウ隔離**

### 識別

匿名ID + 引き継ぎコード（任意でストア連携）。
※ 進行をサーバーが持つ以上「アカウント不要」は成立しない。

## 5. 運営コスト

**月額 $0〜$5、固定費は Apple Developer $99/年 のみ。**

| 項目 | 手段 |
|---|---|
| ホスティング | GitHub Pages / Cloudflare Pages |
| バックエンド | Cloudflare Workers + D1（無料枠: 10万req/日、10万行書き/日） |
| クラウドセーブ | iCloud / Google Play Games |
| **LiveOps** | **日付をシードにした決定論的生成 → サーバー不要・運用工数ゼロ** |
| プッシュ通知 | 端末のローカル通知 |

### チャネル

- **Web版 = 体験版**（ローカルセーブ、深度上限、サーバー不使用）。純粋な集客装置
- **アプリ = 本編**（オンライン、課金）

※ Web版で本編を動かすとサーバーコストを消費して広告しか生まない。
