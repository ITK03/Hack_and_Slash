## 依頼12: 残りの技も倍率方式へ揃え、等級で差を付ける

全技の mul 方式への統一は**すでに完了している**。今回やるのは
**等級（tier）が高いキャラの固有技ほど倍率を高くする**こと。
**ただし差を大きくしすぎない。**

### 現状（測ってある）

キャラは12人、等級は N / R / SR / SSR。固有技の威力（中央値）は今こうなっている:

| 等級 | キャラ | 固有技 | 威力 | 戦士の大地砕き(91.5)比 |
|---|---|---|---|---|
| N | ガイ | 守りの構え | 0（自己強化） | — |
| R | ルカ | 疾風の一閃 | 112 | 1.22倍 |
| R | バルド | 一点突き | 180 | 1.97倍 |
| SR | ゲルト | 不落の盾 | 0（自己強化） | — |
| SR | ヴェルナ | 連斬 | 93 | 1.02倍（再使用0.45秒） |
| SSR | レオンハルト | 覇王断 | 282 | 3.09倍（再使用5.5秒） |
| N | ミラ | 水鏡 | 48 | — |
| R | ノア | 退き風 | 76 | — |
| R | イリス | 星屑 | 90 | — |
| SR | セラ | 氷牙 | 117 | — |
| SR | ファウスト | 焦土 | 136 | — |
| SSR | アルテミシア | 終焉の光 | 255 | — |

### やり方の指定

1. **倍率は「型」と「等級」の掛け算にする。**
   - 型の倍率: 技の種類（扇・突進・全周・貫通など）と**再使用時間・MP消費**から決める。
     再使用0.45秒の技と5.5秒の技に同じ倍率を付けてはいけない。
     **1秒あたりの威力**（倍率 ÷ 再使用時間）が型ごとに近い範囲へ収まるようにする。
   - 等級の倍率: **N=1.00 / R=1.06 / SR=1.12 / SSR=1.20** を推奨する。
     最上位と最下位の差が**2割**に収まる。限界突破の基礎能力補正
     （1.06/1.12/1.20）と同じ刻みなので、ゲーム内で説明が一貫する。
2. **「大きすぎる差」を作らないための上限。**
   同じ役割の技どうしで、**1秒あたりの威力が2倍を超えないこと**。
   いま覇王断が大地砕きの3.09倍あるような開きは、等級差ではなく別物になっている。
3. **自己強化系（ガイ・ゲルト）はダメージが0**なので、等級の倍率は
   **効果量（軽減率・持続・回復量）側に掛ける**。ここも上下2割に収める。
4. **等級補正が二重に効いていないか確認する。** キャラは既に等級由来の
   基礎補正（`hp:1.03` 等）を持っている。固有技にも等級倍率を掛けると二重になる。
   **合わせて何倍の開きになるかを実測し、報告すること。**

### 確認すること

- 全技（戦士・魔術師・固有）について、**1秒あたりの威力の一覧**を出す。
  外れ値（他より2倍以上）が無いこと。
- `check-balance` / `check-playable` を回し、**変更前後の到達深度**を並べる。

## 依頼14: 装備タブの上部を作り直す

### 要求する形

```
┌─────────────────────────────────────────┐
│ ┌──────┐  [装備] [技] [能力] [限界突破]  │
│ │ アイコン │                              │
│ │  (押せる)│  レオンハルト SSR Lv60 戦闘力3,246│
│ └──────┘                                │
└─────────────────────────────────────────┘
```

- **左上にキャラクターアイコン。** その**右に4つのボタン**（装備 / 技 / 能力 / 限界突破）。
- **縦方向を使わない。** アイコンとボタンと名前を**横に並べて1つの塊**にする。
- **アイコンを押すとキャラクター一覧**（アイコンのグリッド）が開き、切り替えられる。
  それ以外の仕様はほとんど今のまま。
- **既定で「装備」が選ばれていること。**
- **4つの中身も、今よりスクロールが要らないようにまとめる。**

### いま何を置き換えるのか（測ってある）

現在は縦に3つ積んでいて、**中身が始まる前に188px**使っている:

| 要素 | 高さ |
|---|---|
| `.charBar`（編成メンバーの横並びチップ） | 65px |
| `.editCard`（編集中の枠） | 66px |
| `.innerTabs`（装備/技/能力の3ボタン） | 57px |
| **合計** | **188px** |

本文の見える高さは686pxしかないので、**上部だけで27%**を食っている。
装備画面は現状62pxぶんスクロールが要る。

**目標: 上部の塊を 100px 以下に収め、装備画面をスクロール0にする。**
達成できたかを**実測して報告すること**（`.sbody` の `scrollHeight - clientHeight` が0）。

### 作り方の指定

- `.charBar` と `.editCard` を**廃止して1つの塊に統合**する。
  編成メンバーの横並びチップは、アイコンを押して開く一覧に吸収してよい。
- 名前・等級・Lv・戦闘力は**1行**に収める。今は3行使っている。
- 4つのボタンは**アイコンの右**に置く。2×2でも横1列でもよいが、
  **押せる領域は44px以上**を守ること（この規則の検査が既にある）。
- 限界突破の中身は、依頼8のとおり「同じ仲間 0/1」の表示にする。
- **既定は装備。** `S.gearSub` の初期値と、読み込み時の既定値の両方を確認する。

### 4つの中身のコンパクト化

**技画面（617px）が最優先。** 他の3画面は60px前後なので、ここだけ桁が違う。
原因は技を全件カード表示していること。**畳む・アイコン化する・種類で絞るなど、
一覧の見せ方そのものを変えること。** 1行にしただけでは足りない。

- **装備（62px）:** 7部位のマスは高さ90px固定を維持（縦長にすると差し戻しになった経緯がある）。
  部位名が消えたぶんを詰める。戦闘力と「おすすめを着せる」の帯も1行に。
- **技（617px）:** 上記のとおり抜本的に。まず「いま3枠に何が入っているか」が
  1画面で見え、変更したい枠を押してから候補を選ぶ形にするのが素直。
- **能力:** 6項目 + 確定/やり直し。説明文を短くして行を詰める。
- **限界突破:** 段階ごとの効果表が縦に長い。畳むか、1行にまとめる。

### 確認すること

- **4画面すべてで**、390×844 でスクロール量が0（または最小）であること。実測値を出す。
- `check:ui` / `check:layout` を通すこと（枠の不揃い・はみ出し・44px・コントラストを見る）。
- キャラクター一覧から切り替えたあと、**選んでいた4つのうちどれが開くか**を決めて報告する
  （切り替え前の画面を保つのが自然だが、判断してよい）。
