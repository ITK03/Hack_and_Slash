装備タブの新しい上部で、**枠が互いに重なって読めなくなっています。**
スクリーンショットで確認した重なりは3か所:

1. **キャラクターアイコンの枠が、装備/技/能力/限界突破の4ボタンに覆いかぶさっている。**

`position:absolute` をやめる、`height` を `min-height` にする、
あるいは素直に flex/grid で組み直すこと。

## 依頼17: 到達していなくても報酬がもらえるバグ

**原因は特定済み。** `claimBeginnerMission()`:

```js
function claimBeginnerMission(){
  if(S.beginnerClaimed)return false;          // ← 受け取り済みかどうかしか見ていない
  const target=beginnerTarget();               // = 100
  const boost=Math.max(1,Math.floor(target*.6));
  if(boost>S.base.lv)forceLevel(boost);        // Lv60まで引き上げ
  for(const slot of SLOTK){ ... 深度60の希少装備を7部位 ... }
  S.beginnerClaimed=true;save();return true;}
```

**到達深度（`S.deepest`）を一度も見ていません。**
ボタンの表示条件も `if(!S.beginnerClaimed)` だけです。
そのため**始めたばかりの深度1のプレイヤーが即座に押して、
Lv60 と深度60の希少装備7部位を受け取れます。**
ラベルが「基準 100F」なので、到達報酬に見えるのに到達判定が無い、という状態です。

**判断が要ります。実装したうえで報告してください:**

この報酬はもともと**後発組の底上げ**が目的で作られています
（`docs/SPEC.md`「初心者ミッションは底上げ専用で、既に基準レベルを超えている
プレイヤーのレベルを下げない」）。つまり「到達していなくても受け取れる」のは
**意図された挙動**でした。ラベルが誤解を招いているのが実際の問題です。

そこで、次の2つを**分けて**扱うこと:

1. **到達報酬**（依頼16の新しい区分）: **`S.deepest >= 目標深度` を必ず確認する。**
   到達していなければ受け取れない。ここが今回直すべきバグ。
2. **初心者の底上げ**: 到達を条件にしない。ただし**名前と説明を、
   到達報酬ではないと分かるものに変える**（例「はじめての支援」）。
   到達報酬の一覧に混ぜないこと。

**確認:** 深度1の新規セーブで到達報酬が受け取れないこと、
到達後は受け取れることを実測して報告する。

## 依頼12: 固有技に等級差を付ける

全技の mul 方式への統一は**すでに完了している**。今回やるのは
**等級（tier）が高いキャラの固有技ほど倍率を高くする**こと。
**ただし差を大きくしすぎない。**

### 現状（測ってある）

キャラは12人、等級は N / R / SR / SSR。固有技の威力（中央値）は今こうなっている:

| 等級 | キャラ | 固有技 | 威力 | 戦士の大地砕き(91.5)比 |
|---|---|---|---|---|
| N | ガイ | 守りの構え | 0（自己強化） | — |
| R | ルカ | 疾風の一閃 | 112 | 1.22倍 |
| R | バルド | 一点突き | 180 | 1.97倍 |
| SR | ゲルト | 不落の盾 | 0（自己強化） | — |
| SR | ヴェルナ | 連斬 | 93 | 1.02倍（再使用0.45秒） |
| SSR | レオンハルト | 覇王断 | 282 | 3.09倍（再使用5.5秒） |
| N | ミラ | 水鏡 | 48 | — |
| R | ノア | 退き風 | 76 | — |
| R | イリス | 星屑 | 90 | — |
| SR | セラ | 氷牙 | 117 | — |
| SR | ファウスト | 焦土 | 136 | — |
| SSR | アルテミシア | 終焉の光 | 255 | — |

### やり方の指定

1. **倍率は「型」と「等級」の掛け算にする。**
   - 型の倍率: 技の種類（扇・突進・全周・貫通など）と**再使用時間・MP消費**から決める。
     再使用0.45秒の技と5.5秒の技に同じ倍率を付けてはいけない。
     **1秒あたりの威力**（倍率 ÷ 再使用時間）が型ごとに近い範囲へ収まるようにする。
   - 等級の倍率: **N=1.00 / R=1.06 / SR=1.12 / SSR=1.20** を推奨する。
     最上位と最下位の差が**2割**に収まる。限界突破の基礎能力補正
     （1.06/1.12/1.20）と同じ刻みなので、ゲーム内で説明が一貫する。
2. **「大きすぎる差」を作らないための上限。**
   同じ役割の技どうしで、**1秒あたりの威力が2倍を超えないこと**。
   いま覇王断が大地砕きの3.09倍あるような開きは、等級差ではなく別物になっている。
3. **自己強化系（ガイ・ゲルト）はダメージが0**なので、等級の倍率は
   **効果量（軽減率・持続・回復量）側に掛ける**。ここも上下2割に収める。
4. **等級補正が二重に効いていないか確認する。** キャラは既に等級由来の
   基礎補正（`hp:1.03` 等）を持っている。固有技にも等級倍率を掛けると二重になる。
   **合わせて何倍の開きになるかを実測し、報告すること。**

### 確認すること

- 全技（戦士・魔術師・固有）について、**1秒あたりの威力の一覧**を出す。
  外れ値（他より2倍以上）が無いこと。
- `check-balance` / `check-playable` を回し、**変更前後の到達深度**を並べる。
